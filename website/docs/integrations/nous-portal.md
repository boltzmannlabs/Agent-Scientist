# Nous Portal

This inherited hosted-service setup page is retired for Agent Scientist.
SCI does not require that account or subscription. Do not follow an upstream
login/install guide as SCI setup instructions.

Use `sci setup` / `sci model` for your chosen LLM provider. Web search uses a
configured supported search provider. Connect existing MCP services with
`/Add_mcp`; service authentication is separate from model authentication.
Boltzmann access requires `/Add_boltz` authorization.

See [SCI installation](../getting-started/installation.md) and the source checkout's
`README.md`. Retained provider compatibility code is not a claim that SCI offers
another vendor's hosted features, free models, billing, or managed services.
