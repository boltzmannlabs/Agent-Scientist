# Bundled Skills Catalog

Sci ships with a large built-in skill library copied into `~/.sci/skills/` on install. Each skill below links to a dedicated page with its full definition, setup, and usage.

Sci also syncs bundled skills on `sci update`, but the sync manifest respects local deletions and user edits. If a skill listed here is missing from your profile's `~/.sci/skills/` tree, it is still shipped with Sci; restore it with `sci skills reset <name> --restore`.

If a skill is missing from this list but present in the repo, the catalog is regenerated by `website/scripts/generate-skill-docs.py`.
