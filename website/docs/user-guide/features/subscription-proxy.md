# Subscription proxy reference

The inherited hosted-subscription setup recipe is retired for SCI. It is not
required for scientific tools, web search, MCP connections, or model login.
Use `sci setup` or `sci model` for your chosen provider and configure each service
separately. Do not forward authentication to an unreviewed proxy or assume that
another vendor's subscription permits third-party use.

Retained proxy/provider compatibility code does not mean SCI supplies a hosted
subscription, billing, or free model credits. See
[SCI installation](../../getting-started/installation.md) and the checkout's
`INSTALLATION.md`. For an agent API, read [API server](./api-server.md).
