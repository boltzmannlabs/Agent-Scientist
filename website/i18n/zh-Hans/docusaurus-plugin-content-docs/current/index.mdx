# Agent Scientist (SCI)

:::info
此页面保留当前 SCI 英文原文；中文翻译仍待审核。安装请使用本仓库的 INSTALLATION.md，不要使用其他产品的安装站点。

Agent Scientist is the Boltzmann Labs customization of an open-source agent.
Use the SCI instructions shipped with your checkout, not another product's
installer, account setup, or hosted documentation. Original licenses and
contributor attribution are preserved in the source distribution.

## Install from your SCI checkout

On Linux or macOS, run as your normal user:

```bash
cd /path/to/agent-scientist
bash ./install-sci.sh
export PATH="$HOME/.local/bin:$PATH"
agent-sci
```

For an unattended server install, use `bash ./install-sci.sh --non-interactive`,
then run `sci setup` interactively to authenticate your chosen model provider.
On native Windows, use `.\setup-sci.ps1` from PowerShell.

The repository's `INSTALLATION.md` is the complete installation guide; its
`README.md` is the canonical SCI user manual. The installer prepares the core
CLI and bundled skills. Web, Electron, and native packages are separate builds
documented there. No signed public installer or public Git URL is promised
until the team configures and validates its own release destinations.

## Scientific workflows

- Add reviewed instructions with `/Add_skill`.
- Add an existing tool with `/Add_tool`, or an MCP service with `/Add_mcp`.
- Authorize Boltzmann with `/Add_boltz`; tools stay locked without valid authorization.
- Create a research project with `/Create_profile`, then select it with
  `/activate "project-name" profile`.
- Provide local files or external URLs as project references. References are
  not automatically uploaded, indexed, or permission to execute software.

Saved capabilities normally become available in the next session. A skill is
an instruction bundle, not proof that software is installed or results are
scientifically correct. Research execution must respect input/output contracts,
permissions, credentials, and artifact validation.
